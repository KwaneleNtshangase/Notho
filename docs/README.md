# Documentation index

- `guides/`: active product, content and deployment guides.
- `audits/`: security, UX, AI-content and store-readiness assessments.
- `supabase/`: database and Supabase operational notes.
- `archive/prompts/`: completed agent prompts and historical handoffs.
- `archive/code-snapshots/`: retained diagnostic code that is not part of the application.

Store-submission material lives in `store-launch/`. Business, research, analytics and learning source documents remain in their clearly named top-level folders because they are independent document libraries.
