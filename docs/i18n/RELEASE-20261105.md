# South African language release, 5 November 2026

Every inventoried English source has a structurally usable record in every selected language. Some records still match English. These are counted separately. Course and lesson IDs, answer scoring, financial values and user-entered data keep their original meaning.

The release includes the About, guides, privacy settings and root error page from production revision `76a9611`. It fixes previously English form placeholders and numeric option labels. English is the default. The other ten languages have an “(under review)” label and a switch back to English. Read-aloud is hidden when a suitable voice is unavailable. The test voice uses the speech-only pronunciation hint “Notto” for non-Nguni voices.
