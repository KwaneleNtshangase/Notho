# South African language release, 5 November 2026

Every inventoried English source has a structurally usable record in every selected language. Some records still match English. These are counted separately. Course and lesson IDs, answer scoring, financial values and user-entered data keep their original meaning.

The release includes the About, guides, privacy settings and root error page from production revision `76a9611`. It fixes previously English form placeholders and numeric option labels. English is the default. The other ten languages have an “(under review)” label and a switch back to English. Read-aloud is hidden when a suitable voice is unavailable. The test voice uses the speech-only pronunciation hint “Notto” for non-Nguni voices.

The three Afrikaans curriculum keys that match English are “1 week”, “God” and “As SARS”. The Xitsonga course title “Credit & Debt” uses English until a reviewer supplies wording that distinguishes access to credit from outstanding debt. The other eight languages have no unclassified English curriculum keys. Elsewhere the counts include browser and code identifiers, shared abbreviations, short controls and unresolved labels. Each language has an exact local worksheet; these counts are not a measure of human approval. Free-service retries were stopped when the provider refused more requests.

The other 1,270 exclusive secured exam sources have a server-only record in each language. All ten public packs were checked for accidental inclusion of those sources. Approved and preserved existing wording takes precedence. The offline review worksheets are excluded from deployment.
